
# Kostya 🎒

**Kostya** is a fun, TypeScript-powered 2D game engine crafted for building classic platformers. Built as a hobby project, it’s all about creating pixel-perfect adventures with a DIY spirit. Jump, collect pickups, and explore tile-based worlds with a lightweight engine made from scratch!

---

## 🌐 Features

- **Classic Platformer Vibes**: Run, jump, and collect with simple physics and pickup mechanics.
- **Pixel-Perfect Rendering**: Powered by WebGL for crisp visuals.
- **Particle Effects**: Add some sparkle to your game (work in progress!).
- **Open Assets**: Uses freely available textures and sounds from open sources.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- [Bun](https://bun.sh/) (for building)
- [npm](https://www.npmjs.com/) (for package management)

### Installation

1. Clone the repo:

   ```bash
   git clone https://github.com/your-username/kostya-game.git
   cd kostya-game
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

---

## 📦 Building for Production

Create a production bundle:

```bash
bun build ./src/index.js --outfile dist/main.js
npm run build
```

To lint your code:

```bash
npm run lint
```
